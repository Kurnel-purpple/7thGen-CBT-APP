Built for real exam halls

No internet?
No problem.

  • Prepare-for-Exams mode pre-loads every exam onto hall computers before the first student sits down.
  • If the network drops mid-exam, answers keep saving locally — and sync automatically the moment it returns.
  • Students never see an error. Teachers never lose a script.

Exam integrity

Malpractice doesn't stand a chance.

  • Per-student scrambling — every candidate sees the questions in a different order.
  • Scheduled release — exams unlock at the exact date and time you set, on trusted server time, not the student's device clock.
  • One-click lockdown — the admin can make every exam unavailable instantly.
  • Idle auto-logout — abandoned student sessions close themselves.
